# 言灵 Yanling — 产品功能说明

> 本文描述**当前已实现**、**半成品/占位**与**规划拓展**能力，便于对内对齐、对外简介或商店说明取材。

## 一、已实现

### 1. 多平台评论（Chrome 扩展 + DOM）

| 能力 | 说明 |
|------|------|
| 支持站点 | **小红书**、**哔哩哔哩**、**抖音** Web（可见 DOM，非官方开放接口爬虫） |
| 抖音场景 | 独立 `/video/{id}`、`modal_id` 等；首页/精选/关注/朋友/发现等**信息流壳层**识别 |
| 采集与同步 | 节流扫描、ingest 去重上报；侧栏与**当前激活标签**、地址栏变化对齐 |
| 过滤本人 | 小红书：登录身份/昵称；抖音：当前账号主页 id 与评论作者链比对 |
| 列表合并 | 页内评论与后端 DB 合并（意向、回复状态等） |

### 2. 智言（侧栏核心）

| 能力 | 说明 |
|------|------|
| 评论列表 | 展示、刷新、**滚动联动**高亮 |
| 筛选 | **全部** / **高意向** / **待处理** |
| AI 回复单条 | 生成建议 → **一键填入**页内回复框；**不自动发送** |
| 主跟评 | **笔记跟评** / **视频跟评**：对当前内容生成主评文案 → 填入底部评论区（独立 API） |
| 已回复 | 填入成功后标记；抖音支持子回复自检与后端 `mark-replied` 同步 |

### 3. 存言

收藏 AI 话术；分类、搜索、删除；与后端存言接口同步。

### 4. 灵主（我的账户）

展示昵称/邮箱、积分（总额/免费额度/充值余额）、客服联系入口、退出登录。

### 5. 驭灵（设置）

语言偏好、产品更新通知偏好（本地）、意见反馈跳转、版本展示。

### 6. 账号与后端

邮箱注册/登录、JWT、`x-tenant-id`、多租户；评论 ingest/列表、mark-replied、AI 回复与跟评、存言、selectors、人设接口等（见 as-built）。

### 7. 合规与法律文案

扩展内服务条款、隐私政策展示；产品定位为用户助理、不代发、不批量绕平台规则。

## 二、半成品 / 占位

| 项 | 状态 |
|----|------|
| 高意向推送通知 | 设置项存在，**未接**系统通知 |
| 评论同步频率（实时/定时/手动） | UI **占位**，不可选 |
| 人设编辑 | 后端有 persona API，侧栏**无完整编辑闭环**，AI 多走默认人设 |
| 编辑资料 / 头像 | 按钮多为**占位** |
| 积分充值 | 展示与入口有，**未接**支付（如 Stripe） |
| 「已回复」全链路 | 仍以插件 + API 为主，文档 TODO 中有后续统一项 |

## 三、规划与拓展

对应项目四大模块与 PRD 阶段（非承诺排期，以迭代为准）。

### 1. Lead Scanner（潜客）— Phase 2 方向

- 统一意向体系（如 🔥✨👀🚫）、**潜客看板**、**SLA** 与逾期提醒  
- 规则 + 模型语义；与成本、队列策略结合  

### 2. DM Convertor（私信）— Phase 3 方向

- **私信脚本**、留资引导；**转化追踪**  
- 节流、人工确认；合规话术（替代违规导流表述）  

### 3. Viral Analyzer（爆款）— Phase 4 方向

- 爆款解析、**自动周报**、复盘视图（与 PRD 数据愿景一致）  

### 4. 平台与矩阵

- **快手**等更多平台；多账号/矩阵与数据汇总  

### 5. 商业化

- **订阅/支付**、积分充值自动化；与驭灵「产品更新」等联动真实触达  

### 6. 配置与风控

- 人设模版库、敏感词与风控、审核开关；**audit_logs** 覆盖关键操作  

### 7. 客户端形态

- **Web 管理后台**（项目规则中的长期规划）与扩展并存  

### 8. 技术与规模化

- 批量队列、缓存、AI 调用日志与预算治理（见工程治理规则）  

### 9. 入驻体验

- 引导流程、可选第三方登录（如 OAuth）、平台绑定说明（PRD Onboarding）
